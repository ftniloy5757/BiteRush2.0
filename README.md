# 🐝 BudgetBee — Personal Finance Manager

BudgetBee is a full-stack personal finance management web application that helps users track income, manage expenses, monitor monthly spending, visualize financial activity, and generate downloadable PDF reports.

Built with **React, TypeScript, Node.js, Express.js, and MongoDB**, with the frontend deployed on **Vercel** and backend on **Render**.

---

## 🚀 Live Demo

Frontend:  
`https://bedget-bee.vercel.app`

Backend API:  
`https://budgetbee-uuev.onrender.com`

## ✨ Key Features

- User registration and login

- Monthly spending limit based on income
- Budget warning system
- Weekly and monthly financial analytics
- Interactive charts with Recharts
- Downloadable monthly PDF reports

- Responsive dashboard

## 🔐 Authentication

BudgetBee uses JWT-based authentication.

```text
Register / Login
      │
      ▼
Password hashed with bcryptjs
      │
      ▼
JWT generated by backend
      │
      ▼
Protected API requests
      │
      ▼
User-specific financial data
```

---

## 💰 Core Financial Logic

Monthly income acts as the available spending limit.

```text
Remaining Balance =
Monthly Income - Monthly Expenses
```

The application warns users as spending approaches the monthly limit and prevents expenses from exceeding the available balance.

## ⚙️ Run Locally

Clone the repository:

```bash
git clone https://github.com/Fardin1023/BudgetBee.git
cd BudgetBee
```

Frontend:

```bash
cd client/BudgetBee
npm install
npm run dev
```

Backend:

```bash
cd server
npm install
npm run dev
```

Create the required environment files:

```env
# Frontend
VITE_API_URL=http://localhost:3001
```

```env
# Backend
MONGO_URI=YOUR_MONGODB_URI
JWT_SECRET=YOUR_JWT_SECRET
PORT=3001
```
